# Contributing to PeaBox AI Workbench

Thank you for your interest in contributing.

## Ways to Contribute

- Report bugs
- Suggest enhancements
- Improve documentation
- Add model providers
- Improve attachment processing
- Add tests
- Improve accessibility and user experience

## Development Setup

1. Fork the repository.
2. Clone your fork.
3. Create a virtual environment.
4. Install dependencies.
5. Create a feature branch.
6. Test your changes.
7. Submit a pull request.

## Branch Naming

- `feature/provider-name`
- `fix/issue-description`
- `docs/topic-name`
- `security/improvement-name`

## Pull Request Requirements

- Explain the reason for the change.
- Describe how the change was tested.
- Avoid including API keys or credentials.
- Update documentation when behavior changes.
- Keep pull requests focused on one purpose.

## Code Style

- Use clear Python naming.
- Add docstrings to public functions.
- Handle provider errors safely.
- Never log API keys or private-key contents.
- Preserve backward compatibility where practical.

## Security

Do not report security vulnerabilities through public issues. Follow the instructions in `SECURITY.md`.
