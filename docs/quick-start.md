# Quick Start

Get running in under 5 minutes.

## Using Ollama

Install a model:

```bash
ollama pull qwen3:8b
```

Launch Workbench.

Choose:

```text
Provider → Direct Ollama
```

Set URL:

```text
http://localhost:11434
```

Click:

```text
Discover Models
```

Select:

```text
qwen3:8b
```

Start chatting.

---

## Using OpenAI

Choose:

```text
Provider → OpenAI
```

Enter:

```text
API Key
```

Click:

```text
Discover Models
```

Select your preferred model.

---

## Upload Documents

Supported formats:

- PDF
- DOCX
- XLSX
- CSV
- PPTX
- TXT

Upload and ask questions.

Example:

```text
Summarize this project plan.
```
