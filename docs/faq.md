# Frequently Asked Questions

## Is PeaBox free?

Yes.

PeaBox AI Workbench is open source under Apache License 2.0.

---

## Can I self-host?

Yes.

You can run everything locally.

---

## Can I use Ollama?

Yes.

Direct Ollama and SSH Ollama are supported.

---

## Can I use ChatGPT?

Yes.

Connect OpenAI through an API key.

---

## Can I use Claude?

Yes.

Connect Anthropic through an API key.

---

## Can I use Gemini?

Yes.

Connect Gemini through a Google AI API key.

---

## Does PeaBox store my data?

Chat history is stored locally.

Cloud providers may store or process prompts according to their own policies.

---

## Can I use private models?

Yes.

Any supported Ollama model can be used.

---

## Can I contribute?

Absolutely.

See:

```text
CONTRIBUTING.md
```

for contribution guidelines.

---

## Does PeaBox support enterprises?

Yes.

Future releases will include:

- Authentication
- Teams
- Workspaces
- RAG
- Role-Based Access
