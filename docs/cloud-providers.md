# Cloud Providers

PeaBox supports multiple cloud AI providers.

## OpenAI

Configuration:

```text
Provider → OpenAI
```

Enter API key.

Examples:

- GPT-5
- GPT-5 Mini

---

## Anthropic Claude

Configuration:

```text
Provider → Anthropic
```

Enter API key.

Examples:

- Claude Sonnet
- Claude Opus

---

## Google Gemini

Configuration:

```text
Provider → Google Gemini
```

Enter API key.

Examples:

- Gemini Flash
- Gemini Pro

---

## OpenRouter

Use hundreds of models from one endpoint.

Examples:

- DeepSeek
- Qwen
- Gemini
- Claude

---

## Groq

Low-latency inference platform.

Examples:

- Llama
- Gemma
- Qwen

---

## LiteLLM

Unified gateway that allows:

- OpenAI
- Claude
- Gemini
- Bedrock

through one endpoint.
