# Attachments

PeaBox can analyze uploaded files.

## Supported Documents

- PDF
- DOCX
- XLSX
- CSV
- PPTX
- TXT
- JSON

## Supported Images

- PNG
- JPG
- JPEG
- WEBP

Image support depends on model capability.

## Workflow

```text
Upload
     ↓
Extraction
     ↓
Prompt Creation
     ↓
Model Analysis
```

## Best Practices

Large documents:

- Upload one at a time
- Start new conversations

Very large files:

- Summarize sections separately

## Limitations

Models have context limits.

Very large files may be truncated.
