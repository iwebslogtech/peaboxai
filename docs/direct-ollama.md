# Direct Ollama

Use local or network-accessible Ollama instances.

## Local Example

```text
http://localhost:11434
```

## LAN Example

```text
http://192.168.1.10:11434
```

## Remote Example

```text
https://ollama.company.com
```

## Discover Models

Click:

```text
Discover Models
```

Workbench loads:

- Models
- Capabilities
- Parameters

automatically.

## Supported Features

- Chat
- Documents
- Images
- Thinking Models

depending on model capabilities.

## Security

Do not expose Ollama publicly without:

- HTTPS
- Authentication
- Firewall rules
